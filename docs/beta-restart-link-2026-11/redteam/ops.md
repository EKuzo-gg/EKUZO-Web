## Classes checked and found closed

- Timeouts: restore is limit 0.8 s plus one select 2.5 s (3.3 s); progress is unchanged at 0.8 + 2.5 + 3.5 = 6.8 s worst case, HMAC adds microseconds; all under Netlify's 10 s. Neon's own 8 s fetch cap does not hold the response (see C2 for the cap value).
- Migration: none needed. Route reads `id`, `session_id`, `updated_at`, `completed_at`, `answers`, `source`, `stage`, `email` from 0006; primary key lookup; no new column or index.
- Cookie path `Path=/api/season1-beta` is prefix-matched on a `/` boundary, so it is sent to `/api/season1-beta/restore`, same origin fetch default credentials include it; cookies set on a 302 from a route handler are accepted for a top-level navigation. Middleware does not run on `/api`, so it cannot touch or strip it.
- CDN caching: the 302 carries `no-store` and a Set-Cookie; the start page is `force-static` and unaffected because the design uses a flag cookie, not a query string (nothing token-shaped can be cached in the HTML). No `headers()` or `netlify.toml` rule matches `/season1/beta/r/`.
- Middleware on the new route is wanted (first-touch origin and UTM last click on the email click); bots are already skipped there. `/season1/beta/r/<token>` has no dot, so the matcher includes it.
- Route handler HEAD and OPTIONS: Next answers HEAD for GET handlers with no database call; restore is POST only, other verbs 405.
- Token and session binding: same session id on a new device continues the same row; original device after 14-day local expiry makes a new session on the first post, which supersedes the link and issues a new one (intended, J4); two devices alternating on the same session id merge answers key by key and stage only moves up (`greatest`).
- Completion: `handleBetaWizard` leaves `session_id` untouched, so a finished row stays `done` for its token (J3), and a straggler inside two minutes returns early before any Klaviyo write.
- Klaviyo: `{{ person.beta_restart_link|default:"..." }}` is valid for profile properties; tracking wraps dynamic hrefs at send time; UTM append is harmless once C1 is fixed (route ignores query); the non-empty reset value on completion covers the empty-string-does-not-overwrite behaviour (R-1). Profiles with no property fall back to the default.
- Cookie flag path `/season1/beta` matches `/season1/beta/start`; page script can delete it with the same path.
- Stranger posting a new session for someone's email kills their link: this is D1/D2 (accepted); they cannot read the token.
