### Notes

1. **No backdrop on the S01 popup.** MN-5 and JR-5 mention dismissal by backdrop. The Season 01 popup is a full-viewport `fixed inset-0` dialog, so there is no outside area. My click at the viewport corner did nothing (rows "JR-5 dismiss via backdrop" in `results-pb.json` show FAIL; that row is a test for an interaction that does not exist, not a defect). Logged as D-10 for the requirement text.
2. **Torn paper 404 root cause (TG-4).** `curl` on both servers (`sentinels-B-and-torn-paper-curl.txt`): the raw path `/images/new%20torn%20paper/torn-paper-red-top-2@2x.png` returns 404 on the branch AND on origin/main; the same path with `@` written as `%40` returns 200. The file exists in `public/` and is tracked. It is the raw static file lookup that fails, not the `/_next/image` optimizer: `components/sections/FooterBanner.tsx:74` uses a plain `<img>`, and that file is byte-identical to main. On `/` the same failure also hits `torn-paper-black-bottom-1@2x.png` and `torn-paper-white-1@2x.png`. So every literal-`@` path under `public/` 404s under `next start`. I could not test Netlify's CDN.
3. **Screenshots.** `docs/gaming-study-ship/screenshots/` was re-taken with `shoot.mjs` plus `scripts/shoot2.mjs` from the first mode-on build (22:20), before another session's uncommitted edits. Added: `post-1440-opening`, `post-375-opening`, `post-1440-sources`, `inbound-{kids-gaming,lol,fortnite,homeschool,sons-friends}-1440`. `screenshots-ready.txt` was written right after. They show the "Short answer:one" spacing defect (D-01).
4. **First build against final build.** Every functional test was run twice (first build, final build). Results agree row for row; final-build outputs are the unsuffixed `results-*.json` and `*-console-final.txt`, first-build outputs are in `first-build-run/`.
