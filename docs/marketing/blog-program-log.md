- Content planning that incorporates **business needs** — the blog is currently a *site-depth proxy* (site never finished after the PixelOne contract ended), and posts must give Karlin & Aaron reusable raw material for pages/ads/content. No canonical list yet.
- Distribution for business value — understand the opportunity per theme and where to leverage links. Homeschool posts were written as tools for that but little has been done.
- Author bios — Karlin & Jamie have pages; two guest posts are bio-less (fine). Possible author hub for a stronger entity signal.
- Blog integration block — re-add a contextual related-posts block on key pages (we removed it pre-content).
- KB preparation — centralizing the company KB soon; make sure it's usable by Karlin & Adam, blog-specifically.
- Reporting — convert manual reports to a cron job, shareable for the Monday meeting; **and clean the data (Jamie's IP isn't excluded, so small numbers may really be ~zero).**
- Blog style — all narrative ~2000-word prose so far. Try shorter posts, media/infographics, and especially **comparison posts** (Jamie historically disliked, but search + AI demand them).

### Overlap = near-total
Both lists converge on: an organizing layer, interlinking + program CTAs,
business-aware planning, distribution activation, and measurement. The series
idea (Jamie) and the corpus-index idea (Claude) are the same backbone.

## Proposed session structure (~7 sessions + a continuous content track)

Sequenced so quick wins and process fixes land early; the big "spine" (series +
plan) is broken into digestible pieces. Reorder freely by energy/timing — the
process sessions (S6 reporting, S7 distribution unblock) are independent and can
jump the queue.

- **S1 — Review, align, quick win, set up this log.** ✅ (this session) Loaded full context, reconciled both lists, connected EKUZO100 + sibling links to the 3 unlinked posts, created this log.
- **S2 — Themes & series definition.** Conversational/strategic, no build. List the themes we have + plan to have, cluster them, name 3–5 series, slot every existing post into one (and make keep/improve/retire calls). Confirm the demand-atlas priority order. *Output: the series taxonomy.* ← Jamie named this as the next step.
- **S3 — Canonical business-aware content plan.** Reconcile keyword map + demand atlas into one ranked plan; add columns for business need (which unbuilt page it proxies), raw-material value for Karlin/Aaron, intent/impact/opportunity. Slot comparison + light-format posts in. *Output: the canonical roadmap.*
- **S4 — Schema + taxonomy build.** Implement series as `CreativeWorkSeries` + `isPartOf` + `CollectionPage` hubs; convert index categories → series; stretch the index framing; fold in the author-entity signal. (Claude Code / Aaron lane.)
- **S5 — Interlinking, on-page blog block, existing-8 cleanup.** Finish hub-and-spoke everywhere; add contextual blog blocks to key pages; execute keep/improve/retire; Faith→Karlin doc hygiene; fix empty headings.
- **S6 — Reporting & measurement.** IP exclusion; decide GA4 data path (verify Cowork-can-load-MCP); stand up automated weekly digest for the Monday meeting; design the monthly AI-citation audit.
- **S7 — Distribution motion.** Per-theme leverage map; launch the homeschool pilot; Quora-under-Jamie path; syndication (LinkedIn/Beehiiv/X). Ongoing thereafter.

**Continuous track — content production (L):** whitespace + series posts ship at the deep/light cadence between sessions, fed by the S3 plan. Not a session; an ongoing flow.
