# Deliberately NOT disallowed for User-agent: * — a disallowed URL can still
# be indexed from an inbound link, because the crawler never fetches the page
# and so never sees its noindex. Search engines get the noindex meta tag plus
# the X-Robots-Tag header instead, which is the reliable signal.
#
# AI and training crawlers are the opposite case: most honor robots.txt, many
# ignore noindex, and none of them need to index anything. So they get an
# explicit path block. This is scoped to the single path on purpose — EKUZO
# wants AI crawlers on the rest of the site (see GEO-CITABILITY-SCORE.md).
